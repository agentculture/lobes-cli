## Update 2026-10-18 ~05Z: strict + thinking solved; next is t13 (spark2)

**Root cause (d5): our plugin, not the engine.** vLLM 0.30 and later start the
structured-output grammar only **after** reasoning ends. The plugin's grammar
begins with the thinking block, so the matcher sits inside it, accepts every
tool call as thinking text, and masks EOS until `max_tokens`. It reproduced on
0.30.0, 0.31.0 and eugr 0.32.0rc1, and with DSpark off. Passing
`reasoning=False` fixes it on 0.31.0 and eugr: 1 call, reasoning kept, and a
`maxLength=3` control is still enforced. The old nightly needs the current
per-request derivation, so the packaged fix must detect the engine (R2, t14).
Evidence: `docs/evidence/2026-10-18-accept-vllm-031-spark-cortex.txt`.

**Engine (d6):** official 0.31.0 everywhere. The Spark measured 15.9 tok/s on
0.31.0 and 17.2 on eugr (the nightly baseline is 17.0). d3 and d4 are withdrawn.

**Live hand-patch on the Spark:** `~/.lobes/qwen3_thinking_tool_parser.py`
line 143 passes `reasoning=False` (backup `.bak-*-reasonfalse`). Do **not**
run `lobes doctor --refresh-plugin --apply` on the Spark before the R2 plugin
lands: it would restore the broken copy.

**Next: t13 (spark2).** Install `uv`, then scaffold plus switch in one
recreate (runbook). Pin `v0.31.0-ubuntu2404`, and apply the same

## Findings to carry into R2 (t14–t17) and follow-ups

- **Mixed-engine pooling.** The mesh fingerprint has no engine version (c34).
  A 0.30.0 Spark and a nightly spark2 pool as one plain `cortex`, so measure
  through `cortex-spark` / `cortex-spark2`.
- **Memory gate.** On the Thor, a stopped engine's memory stays held until a
  page-cache clear runs after the stop. `lobes up` clears only before
  (documented in the runbook's Thor notes).
- **No page-cache grant.** The Orin and the Spark have none: sudo needs a
  password. The operator runs `orin` / `spark grant-permissions` themselves.
- **Orin chain mismatch.** The Orin's CLI chain includes audio files the
  gateway never had. Recreate there with the gateway's label chain and
  explicit `docker compose -f ... --no-deps`.
- **Governor (code follow-up).** It must refuse a container without explicit
  `/dev/nvidia*` devices, and its default bands don't fit a Spark whose acpitz
  zones idle around 88 °C.
- **Named costs:**
  - Spark cortex decode on 0.31.0 was about 83% of spark2's nightly (14.0 /
    14.4 vs 17.0 / 16.9 tok/s);
  - Orin embedder about 13% slower;
  - Orin reranker about 7% slower.
- **Filed issues:** #321 (`assess --port` drops the key) and #322 (`--probes
  --role cortex` ignores `--model`).
- **Lapses l1–l10** are filed, for adjudication at `/summarize-delivery`.
